# 沉浸式个人网站「一个人的小小宇宙」

通过可旋转目录组织内容的沉浸式展示网站。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 可拖动、吸附和直接跳转的旋转目录。
- 介绍、兴趣、摄影、项目、随笔和联系栏目模板。
- 大图浏览、详情页、响应式布局和中英文切换。

## 运行

需要 Node.js 22.12+。运行 `npm ci`、`npm run dev`；`npm run build` 构建。`src/data` 为匿名示例内容，图片为图库示例，不代表作者个人经历或原创摄影。

## 当前范围

已有React、TypeScript网站框架。

- 展示内容和图片仍包含示例素材。

## 验证

`npm run build` 成功。
